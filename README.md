# Warehouse Allocation System

## Tech Stack

* Java 17
* Spring Boot
* Spring Data JPA
* MySQL
* Swagger

## Features

* Warehouse CRUD
* Product Management
* Inventory Management
* Stock Allocation
* Stock Transfer
* Pagination & Search
* Soft Delete

## Setup Instructions

1. Clone project
2. Create MySQL DB: warehouse_db
3. Update username/password in application.properties
4. Run application
5. Open Swagger:
   http://localhost:8080/swagger-ui.html

## APIs

* /api/products
* /api/warehouses
* /api/inventory
* /api/allocations
* /api/transfer
